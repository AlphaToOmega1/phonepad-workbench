# 常见问题与退出/回滚

## 手机连接超时

- 电脑和手机必须存在可达的局域网路径；电脑连接手机热点可用，但不同机型、网络隔离策略会影响可达性。
- 优先使用已能打开页面的手机浏览器。先确认地址对应当前热点网卡，换网后电脑界面的二维码会随服务写出的地址更新。
- 不必为了测试强行退出代理。系统 HTTP 代理与 TUN 接管不是一回事；需检查局域网地址是否被代理规则或 TUN 捕获。修改规则前记录原值，确认后再改。
- 如访问 `/ping` 能得到正常响应，但页面不正常，检查完整链接的访问参数是否保留。
- 如果已有旧版 PhonePad 占用 8765，先退出旧版。发布副本不能和旧版共享同一个端口与配置；不要把本仓库直接覆盖旧项目。

## 上传图片失败或电脑找不到

手机原页面点“传图”会进入同服务的上传页，无需另一个二维码。支持 JPG/PNG/WebP，单张 20 MB；留意进度和失败文字，截图错误提示反馈。支持多选，但重试所选全部时可能产生重复副本。

图片在 `phonepad/received_images`，不是其他旧项目目录。电脑“发送文件”页的“查看手机传来的图片”直接打开这里。

## 图片积累太多

手机接收页点“移除”或“清空图片”，确认后移到 `phonepad/.removed_sent`。误操作时，找到对应文件，移回 `phonepad/发给手机`，刷新手机列表。此操作不清理手机已经下载的图片，也不删除电脑原图。

## 录音没有文字 / F8 无效

检查 AudioRelay 是否真的输出到虚拟麦克风，而不只是显示已连接。确认语音页选择的设备，查看音量条；关闭多余的旧版识别程序，避免抢占 F8/F9。不要同时运行独立 ASR 与集成 ASR。

Windows 未授予麦克风权限、驱动断开、GPU DLL 不匹配都会影响语音。CUDA 错误可先检查包版本和 DLL；也可在配置中临时切换 CPU/int8，但速度可能明显变慢。没有本地模型时不会自动联网下载。

## 关闭窗口后手机仍能连接

后台 HTTP 服务与界面独立运行。完全退出可在任务管理器中按“命令行”定位**本仓库 `phonepad/server.py`** 对应的进程，确认完整路径后结束这一项。不要结束所有 Python 进程。关闭应用不自动删除已接收文件。

## 回滚与迁移

部署到独立新目录，旧项目和原驱动保持原样。确认新目录可用后，再把桌面快捷方式指向新项目根目录 `start.bat`；回滚时指回旧启动器即可。

模型可通过绝对路径复用，不必复制。迁移私有数据需自行决定；不要提交 `*.local.json`、访问参数、图片、模型和日志。访问参数需重置时，先停当前服务，备份再移走 `phonepad/.access-token.local`，下次启动会生成新参数，旧二维码随之失效。
