# 发布状态：公开源码预览版

整理日期：2026-11-05。

本次更新为界面版本 1.6.1；修复 Windows 拖放闪退和手机列表不自动更新，维护者已反馈实际拖拽成功，详见 [更新日志](../CHANGELOG.md)。实际 Windows 崩溃记录留在本机，未上传。

2026-11-07 增补清理功能：清空全部待接收文件（含 PDF/电子书）、手机一键清空电脑发来的文字并同步电脑发送框。通过临时样本的文件下载/回收、原文件保护、访问与版本校验、同窗口文字同步测试；未清空使用者真实文件或接收文字。

2026-11-08 优化手机文字上屏：服务端将逐字符注入改为批量 Unicode `SendInput`，不再逐字等待，也不读写剪贴板；批次间验证前台窗口，并串行处理并发文字请求。4 项模拟检查通过，维护者已在实际使用中确认发送的文字成功快速上屏。自动化测试框未取得稳定前台焦点，因此没有作为实际应用验收依据。

- 当前电脑仍运行原部署位置，整理动作没有替换运行环境、驱动、代理、防火墙或桌面快捷方式。
- 本目录是单独的可发布源码，包含完整手机网页、HTTP 服务、互传 GUI、可选本地 ASR 和测试。
- 新的便携入口与随机访问参数属于发布准备改动；尚未声称另一台干净 Windows 已完成安装验收。
- 原环境完成过 GPU 加载及合成音频识别管线检查。自动断句的队列测试验证了上一句识别阻塞时下一句仍可收音，但不代表真人、方言、噪声场景的识别性能验收。
- 本源码包不携带模型、驱动、CUDA DLL、收到的图片、录音、日志、私人文字或原机器的访问参数。
- 仓库：<https://github.com/AlphaToOmega1/phonepad-workbench>；维护者已决定公开开源，项目自身源码采用 MIT 许可证。
- 发布包检查通过：Python 源码语法；已知个人路径/私人局域网地址/旧固定访问参数排除；便携配置在临时副本中生成；随机访问参数持久化与旧参数拒绝；本地网页、上传与图片字节一致性；5 项核心测试与 5 项断句/连续队列测试。检查未实际录音，也未安装新依赖。
- 第三方库、AudioRelay 与模型权利独立，使用者需自行取得相应依赖。

发布前建议在另一台 Windows 测试：基础互传从零启动、手机热点、代理开/关、双向图片与移除恢复、实际音频中英混合、F8/F9 与管理员权限窗口行为。未完成项目须如实留在文档里。
