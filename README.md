# 手机工作台 · PhonePad

Windows 与手机之间的局域网互传工具。打开电脑端直接显示二维码；手机扫一次，在同一页面输入文字、上传图片、下载电脑文件。可选的本地语音页复用离线 Whisper 模型，F8 开始/结束，停顿后自动出字。

[GitHub 仓库](https://github.com/szwnb/phonepad-workbench) · [MIT 许可证](LICENSE) · [如何贡献与反馈](CONTRIBUTING.md)

当前是**源码预览版**。已有功能在维护者的 Windows 环境验证，尚未完成另一台全新电脑从零安装验证。安装包、驱动与模型不包含在仓库中。

## 先选你需要的功能

| 功能 | 需要什么 | 是否需要模型 / GPU |
| --- | --- | --- |
| 手机文字上屏、双向文件/图片、电脑文字同步 | Windows 10/11、64 位 Python、手机浏览器、局域网/手机热点 | 不需要 |
| 图片列表的小尺寸缩略图 | 在上面基础上安装 Pillow；缺少时回退到原图预览 | 不需要 |
| 手机作为电脑麦克风、本地识别 | 另装 AudioRelay 手机端与电脑端及其虚拟麦克风，ASR 依赖与本地模型 | 模型必需；GPU 可选，CPU 速度未实测 |

**注意两条语音路径的区别：**手机网页只是发送你输入的文字。手机键盘上的语音输入是否走云，取决于所用输入法；本项目不能保证它离线。需要完全本地识别时，使用 AudioRelay → 电脑“语音输入”页。

## 最短安装步骤：先使用互传

1. 安装 Windows 64 位 Python，确认带 Tkinter。建议使用 Python 3.10/3.11；开发环境实际复用了 Python 3.9.13。
2. 下载或克隆仓库到自己有写入权限的目录，解压完整文件，保留 `phonepad` 与 `asr` 文件夹。
3. 打开终端进入项目目录，创建独立环境（下面以 Python 3.11 为例）：

   ```powershell
   py -3.11 -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   ```

   第一条命令不安装 Python 本身；机器没有 3.11 时，先安装它，或把版本号换成已有且兼容的版本。只用基础互传也可以暂时不装 Pillow。

4. 双击根目录 `start.bat`。它会创建本机配置、随机访问参数并启动本地服务，再显示二维码；不会自动下载模型或安装驱动。
5. 让电脑连接手机热点，或让电脑与手机连接同一路由器。用手机浏览器扫码打开。已连接的手机在原页面继续使用，无需为传图再扫一次。

首次使用若 Windows 弹出防火墙提示，只授权你信任的当前网络。项目不会自动修改代理、TUN、防火墙、DNS 或音频默认设备。手机热点可能被 Windows 识别为公用网络，需按当前网络类型检查权限。

## 日常怎么用

| 方向 | 电脑端 | 手机端 |
| --- | --- | --- |
| 手机文字 → 电脑输入框 | 把光标放到目标输入框 | 输入文字，点“上屏”；换行可能触发目标应用的回车行为，发送前请确认内容 |
| 手机图片 → 电脑 | “发送文件”页点“查看手机传来的图片” | 原输入页点“传图”，选照片，再点“发送到电脑”；有进度与错误提示 |
| 电脑图片/文件 → 手机 | “发送文件”选择或拖入文件 | 点“从电脑下载文件”；最新加入的在前，有缩略图，点“下载原图” |
| 电脑文字 → 手机 | “发送文字”粘贴/编辑文字 | 原页面约两秒内自动显示；点“复制文字” |
| 清理待发送图片 | 可在本地查看回收目录 | 每项“移除”或顶部“清空图片”，均先确认；其他文件和电脑原文件保留 |

上传每张限 20 MB，支持 JPG/PNG/WebP。电脑发到手机的文件不是推送到系统相册：手机需要点击下载；浏览器的保存行为由手机决定。

访问二维码带本机访问参数，请只给自己的设备使用。HTTP 服务监听所有网卡的 `8765` 端口，适用于可信局域网，未提供公网部署或 HTTPS 安全加固。

## 本地语音识别（按需配置）

先确认互传可用，再阅读 [本地语音环境与安装](docs/ASR_SETUP.md)。不使用语音时，不必安装 ASR 依赖、模型或 AudioRelay。

语音页使用本机模型。F8 开始持续录音，默认停顿约 0.8 秒后识别上一句，识别期间继续收音；再按 F8 结束并处理尾句，F9 取消。取消“停顿自动出字”可回到手动整段识别。总等待还包括模型运行和排队时间，不能保证实时。

“录音期间静音外放”是可选项，停止后恢复。能量断句、Whisper VAD 与低频过滤**不等于声纹识别**，不能保证只识别使用者本人，也不能保证消除旁人或电视人声。

## 数据保存在什么地方

| 路径 | 内容 |
| --- | --- |
| `phonepad/received_images/` | 手机传来的图片 |
| `phonepad/发给手机/` | 电脑准备给手机的副本 |
| `phonepad/.removed_sent/` | 被移除的副本；移回“发给手机”可恢复 |
| `phonepad/.shared-text.local.json` | 主动粘贴并发布的电脑文字；界面清空可清除 |
| `phonepad/.access-token.local`、`手机地址.txt` | 本机访问参数和地址，不能提交到 GitHub |
| `asr/config.local.json`、`preferences.local.json` | 模型设置与偏好 |

录音只在内存处理，不保存音频。项目不主动上传图片、文字或录音到远程服务；可选 AI 纠错仅请求本机 Ollama，但本预览版没有为其提供快捷入口。所有本机数据路径均已列入 `.gitignore`。关闭工作台窗口不关闭手机互传后台；退出后台请按 [故障与停止说明](docs/TROUBLESHOOTING.md) 操作。

## 验证与限制

已验证：原环境中的手机热点连接、文件列表/缩略图/原图下载、单项及批量图片移除与恢复副本、上传文件字节一致性、文字接收接口、同窗口语音页、拖放消息处理、连续断句队列、原环境 GPU 模型加载与合成音频推理。中文/英文真人准确率、移动端所有浏览器和新机器安装速度不作保证。

发布包的源码经过隐私扫描与语法/回归检查；完整验证记录见 [发布状态](docs/RELEASE_STATUS.md)。Windows 专用，尚未支持 macOS/Linux 输入注入。两台手机可访问同一服务，但文字输入并发没有完整排队仲裁，建议一台设备操作“上屏”。

## 开发与测试

```powershell
.\.venv\Scripts\python.exe asr/tests/test_core.py
.\.venv\Scripts\python.exe asr/tests/test_continuous.py
```

测试包含虚拟输入与队列场景，不会实际录音。完整测试需安装 `requirements-asr.txt`。源码结构：`launch.py` 是便携启动器；`phonepad` 是 HTTP 服务与互传界面；`asr` 是按需加载的识别与输入逻辑。
